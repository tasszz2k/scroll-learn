Privacy policy.

Effective November 16, 2026. This page covers the ScrollLearn Chrome extension and the owner's personal Gmail tool. Both are personal, open-source projects by Tass.

ScrollLearn extension

  • All your data (decks, cards, notes, notebooks, settings, and stats) stays in your browser, in chrome.storage.local and IndexedDB. ScrollLearn has no server and no account system.
  • ScrollLearn has no analytics, no tracking, and no ads.
  • Some features send data to third-party services, only when you use them:
    • Translation of a captured word or sentence: Google Translate.
    • Word family lookup for English words: Datamuse.
    • AI assist: Google Gemini, in your own Gemini session or with your own API key.
    • Text-to-speech: ElevenLabs or the Kokoro Hugging Face Space, with your own key.
    • Update check: the GitHub Releases API.
  • API keys that you enter stay in your browser. ScrollLearn sends them only to the service that they belong to.

Personal Gmail tool

  • This tool is for the owner's own Gmail account only. It is not offered to other users.
  • It uses the Gmail API to read unread messages and mark them as read. It requests the https://www.googleapis.com/auth/gmail.modify scope for this purpose only.
  • It does not sell, share, or transfer Gmail data to any third party. It does not use Gmail data for advertising or to train AI models.
  • OAuth credentials stay on the owner's machine. Message content is processed in memory and is not kept after processing.
  • The use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
  • You can remove access at any time at myaccount.google.com/permissions.

Contact
